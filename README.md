# 📝 Student Registration Form with JavaScript Validation

## 📌 Overview

A responsive Student Registration Form built using HTML, CSS, and JavaScript. The project validates student details before displaying a successful registration message.

## ✨ Features

- 👤 Full Name validation
- 📧 Email address validation
- 📞 10-digit phone number validation
- ⚧️ Gender selection validation
- 📅 Date of Birth validation
- 📚 Course selection
- 🏠 Address validation
- ⚠️ Clear error messages for invalid fields
- ✅ Registration success message
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
